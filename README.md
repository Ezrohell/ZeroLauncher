# ZeroLauncher
ZeroLauncher: fast app search, file manager, ZIP/7z/TAR/GZIP/BZIP2 archive tools, local ADB utilities. Uses Scoped Storage and SAF only. ADB targets Wireless Debugging on Android 11+ with an operation allowlist, not shell. Java-first, modular; file/archive/ADB/deployment are stubs. Min SDK 29, compile SDK 37. Early scaffolding only. Android 10 min.
